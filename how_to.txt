===========================================================
  EVE PI TEMPLATE GENERATOR — HOW TO USE
===========================================================

-----------------------------------------------------------
GETTING STARTED
-----------------------------------------------------------

Double-click "Eve PI.exe" to launch the app.
  OR
Run from source:  python PI.py

The executable is self-contained. Planet artwork, the Scout's
offline map snapshot and the planet icons all travel inside
it, so you can move the .exe anywhere. It creates a "data"
folder beside itself the first time it runs, for the things
it writes: your saved templates, the work history and your
settings.

The window is one screen split in two: the settings on the
left, and the colony those settings describe on the right.
They are the same job, so they are in the same window — you
change a number and watch the planet answer.

Down the far left is a narrow rail with four destinations:

  Build             the settings and the planet
  Library           your saved colonies, as cards
  Proximity Scout   find a planet to build on
  JSON              paste a colony in, copy one out

Build, Library and JSON replace what you are looking at. The
Scout opens its own window and leaves the rail where it is,
because you go looking for a planet *while* you are building,
not instead of it.

Settings live behind the gear icon at the top right, from
every screen.

THE WINDOW SIZES ITSELF

  You should never have to scroll to see your own colony, so
  the window height follows what there is to show. A small
  P1 colony gets a short window; a P4 with a long bill of
  materials gets a taller one; clearing it shrinks back.

  Only the height moves — nothing overflows sideways.

  If your screen cannot fit what the colony needs, the text
  size steps down in small increments rather than cutting
  anything off, and steps back up when there is room again.
  Your own text-size setting is never overwritten by this.

-----------------------------------------------------------
STEP 1 — DESCRIBING THE COLONY
-----------------------------------------------------------

NOTHING IS CHOSEN WHEN YOU OPEN THE TOOL

  All three dropdowns read "Choose a…", and the right half
  shows an empty barren planet with a single launch pad.
  That is deliberate: the tool should not open describing a
  colony you never asked for.

  Choosing a product does NOT choose a chain for you, and
  choosing a chain does not choose a planet type. A setting
  you did not pick should not read like one you did — and
  the panel stays quiet until all three are yours.

  What is already chosen and still valid is kept. Switching
  product inside the same chain leaves the chain alone.

THERE IS NO "GENERATE" BUTTON

  There used to be, and it offered to produce a colony the
  panel had already calculated. The moment product, chain
  and planet type are all set, the colony is drawn, priced
  and complete on the right.

  Everything after that adjusts what is already there.

Work down the numbered panels:

  1. PRODUCT
     Pick what you want the planet to produce. The dropdown
     lists every PI commodity with its tier, e.g.
     "Robotics  [P3]", sorted P1 → P4.
     Choosing a product decides which chains are offered
     next, so always set this first.

  2. CHAIN
     How the product gets made. Only chains that can produce
     the selected product are listed:

       P0 → P1 (Extraction)
         Extractor + basic factories. The classic mining
         planet.

       P0 → P2 (Extraction)
         Self-sufficient planet: extracts its own raw
         resources, refines them to P1, then to P2. If the
         planet only holds one of the two raw resources it
         still works — the other P1 is imported.

       P1 → P2 (Factory)
         Import P1, produce P2.

       P1 → P3 (Factory)
         Two-stage planet: one bank of factories turns P1
         into the P2 intermediates, a second bank turns
         those into P3. You only haul P1.

       P2 → P3 (Factory)
         Import finished P2, produce P3. Far more output
         than P1 → P3, but more hauling.

       P1 → P4 (Factory)
         Deepest chain: P2 and P3 factories on the planet
         feed a single High-Tech facility. Least hauling,
         lowest output.

       P2 → P4 (Factory)
         Import P2, build P3 on-planet, assemble P4.

       P3 → P4 (Factory)
         Import finished P3, assemble P4. Highest P4 output,
         most hauling.

  3. PLANET TYPE
     Only valid planet types are offered:
       - P4 chains are limited to Barren and Temperate,
         the only types that allow a High-Tech facility.
       - Extraction chains list the planet types that
         actually hold the raw resources.

     This is the choice that brings the colony to life. Make
     it and the planet on the right fills in.

  4. PLANET RADIUS (km)
     Type the radius of your actual planet. Find it in-game:
     select the planet, then Information → Attributes →
     Radius. Defaults to 5000.

     Get this right — it decides how many factories you get.
     A link's CPU and power cost grow with its length, and
     structures sit at fixed angles, so the same layout on a
     bigger planet means longer links and a bigger bill:

       CPU   = 15 + 0.20 per km
       Power = 10 + 0.15 per km

     On a 1,200 km planet a link is ~14 km and costs about
     18 CPU. On a 30,000 km planet the same link is ~360 km
     and costs 87. Across a whole colony that is the
     difference between 21 factories and 18. Enter a radius
     smaller than the real one and the tool will hand you a
     template EVE refuses to import.

     On a P0 → P1 planet a checkbox also appears here:
     "Include Storage Facility (P0 buffer)". It puts a
     Storage Facility between the extractor and the
     factories, so raw material that arrives faster than the
     factories consume it has somewhere to sit instead of
     being lost. Worth it if you run short extraction
     programs that spike well above the average yield.

  5. COMMAND CENTER LEVEL
     Your Command Center Upgrades skill (0–5), as clickable
     badges. Higher levels mean more CPU and power, so the
     generator has more to work with.

  6. LAYOUT
     There is no single correct PI layout, so the decisions
     that actually shape a colony are yours.

     Extractor yield — units per head per hour, shown only
       for extraction chains. This is the number the whole
       chain is balanced against: one basic factory eats
       6000 units an hour, so a 10-head extractor at 2000
       feeds three of them. Raise it if your deposits are
       rich, lower it if the extractors run dry.

     Set counts myself — tick this to place exact numbers of
       extractors, heads, factories, pads and arm length.

       Ticking it fills the boxes with what the generator
       just chose on its own, so it doubles as a readout: you
       see the colony is 21 factories on 4 pads without
       changing anything. Ticking never changes the layout,
       it only shows you the numbers behind it. Edit from
       there, or untick to hand the decision back.

       Heads is per extractor, not the total. 0 in any box
       means "you decide" for that one. Manual values are
       placed as asked, even bad ones: the panel then tells
       you what is wrong instead of silently refusing.
       Available for the extraction and single-stage factory
       chains; the multi-stage layouts (P1→P3, P1→P4, P2→P4)
       are fixed by geometry.

     Arm len — how many factories may chain off one side of a
       pad. Factories hang off a pad in two arms, so a pad
       seats twice this number: the default 4 gives the
       familiar 8 per pad, 6 gives 12, and the maximum 8
       gives 16. Leave it at 0 for the default.

       Raise it when you want the same factory count on
       fewer pads. A pad costs 3600 CPU and 700 power, so
       dropping one pays for several extra factories — the
       24-factory build (Pads 2, Factories 24, Arm len 6) is
       the standard use: it fits inside a level 5 command
       center where 24 factories on three pads does not, and
       leaves you two banks of 12 to split between two
       different P2 products on the same planet.

       The cost is link load. Traffic stacks toward the pad,
       so the link nearest it carries every factory behind
       it, and a level-0 link moves 1250 m3 an hour. Light
       cargo never notices: 24 P1 → P2 factories on arms of 6
       peak at about 227. Bulky cargo does — a P3 → P4 planet
       on arms of 6 already runs at 1123, and arms of 7 go
       over. The panel tells you either way, so there is
       nothing to compute by hand.

       Affects the single-stage factory chains (P1 → P2,
       P2 → P3, P3 → P4). Extraction planets place their
       factories around the extractor instead and ignore it.

     The strip at the bottom of the panel measures whatever
     is currently configured, updating as you type:

       CPU and power bars against your command center,
         green until 90%, amber to 100%, red beyond it.
         These include every link priced by its real length,
         so they move when you change the planet radius in
         ④ even though nothing else about the colony did.
       "storage lasts Nh (Nh asked)" — green when it meets
         the interval, amber when it falls short. When it is
         already comfortably past it, the line reads
         "already covered", which is your confirmation that
         the interval is satisfied rather than ignored.
       "extract N/h · factories use N/h" on extraction
         chains — red when the factories outrun the ground.
       Any number of ⚠ warning lines in red, including a
         link named as carrying more than 1250 m3/h — see
         Arm len above.

     Your yield choice is remembered between sessions; the
     manual counts are not.

-----------------------------------------------------------
COLLECT EVERY — ON THE PLANET
-----------------------------------------------------------

The collection interval floats on the planet itself, top
left, as a small bar: 6h · 12h · 24h · 48h · 72h · 168h.
Drag it by the ⠿ handle if it sits over something you want
to see.

It is there rather than in the settings column because its
answer is written on the planet — in the drop-off panel and
in "storage lasts". The control and its result were at
opposite ends of the screen.

It is a MINIMUM, not a target: the generator adds launch
pads, and if that is not enough drops factories, until the
colony can survive that long unattended. If it already lasts
longer, nothing changes and the panel says so.

So whether it does anything depends entirely on the chain:

  P3 → P4 — changes every step. At level 5: 16 facilities
    on 2 pads at 6h, 12 on 3 pads at 12h, 8 on 4 pads at
    24h, 4 on 4 pads at 48h.
  P1 → P2 — nothing until 48h; the default build already
    survives about 34 hours.
  P2 → P3 — nothing until 24h, then 13 on 4 pads at 48h.
    Its P3 output is bulkier, so it fills pads faster.
  P0 → P1, P0 → P2 — usually nothing at any setting. P1 and
    P2 are compact, so one pad already holds several days.

In short, it bites on planets you have to feed. A planet
that mines its own input has almost nothing accumulating
except its finished goods, and those take days to fill a
pad. If you want more storage there anyway, tick "Set counts
myself" and raise Pads by hand — each pad added multiplies
the time.

On a chain whose geometry is fixed, the bar reads CHECK
AGAINST instead of COLLECT EVERY: there the interval judges
the colony rather than resizing it, and a title promising to
collect would be a lie.

-----------------------------------------------------------
STEP 2 — READING THE COLONY
-----------------------------------------------------------

The right half shows, top to bottom:

  - A toolbar: Copy JSON, Reset View, Save to Library,
    Start over
  - The import notice
  - The JSON, exactly as EVE will read it
  - The colony drawn on the real artwork of the planet type
    you picked

To import into EVE Online:
  1. Click "Copy JSON"
  2. In EVE, open the planet's Planetary Interaction view
  3. Use the in-game template import and paste

The planet stays put — panning and zooming move the colony
over it, not the world behind it.

The map has a legend in the corner covering Launch Pad,
Storage Facility, Basic Industry, Advanced Industry,
High-Tech Industry and Extractor (ECU).

Drag to pan the map, scroll to zoom. Hover any structure for
a tooltip listing what it consumes and produces per cycle. On
pure factory planets the Launch Pad tooltip also estimates
how long it takes to fill up, so you know how often to
collect.

An extractor wears its head count as a small badge. That
number decides everything downstream — what the ground gives,
so how many factories run — and it should be readable without
hovering each one.

WHAT THE LINES MEAN

  Cyan dashes are the physical links, and they flow in the
  direction goods travel. Hover a structure and its ROUTES
  light up too, one colour per commodity, so you can follow
  where a material actually goes.

IT FOLLOWS YOUR SETTINGS

  Change a factory or pad count and the map, the CPU/PWR
  figures and the JSON all redraw. There is nothing to
  regenerate.

  What a change is allowed to do depends on what it means.
  Product, chain and planet type describe a *different*
  colony, so they rebuild it. Radius and command center
  level only change what the existing layout costs, so
  nothing moves. The counters edit the colony in place and
  keep every structure you positioned yourself.

START OVER

  Next to Save to Library. It empties the planet and returns
  all six steps to how they were at launch.

  If you have arranged structures by hand and not saved
  them, it asks first: save to library, discard, or cancel.
  A colony the panel just generated is not worth asking
  about — it is three clicks from being reproduced — so it
  does not ask.

SAVING IT

  "Save to Library" asks for a name and stores the colony as
  "Custom - <name>.json", so it appears in the Library
  straight away.

  It saves what is on screen — including any building you
  dragged — not the template the screen opened with.

MOVING A BUILDING

  Drag any structure to move it. The CPU and power figures
  at the top change while you drag, not after, so you can
  see what a longer link costs before you let go. Press
  Escape mid-drag to abandon it; a click that never moves
  just selects.

  If two buildings end up too close, both get a dashed red
  ring. That is a warning, not a refusal — the same way the
  tool lets you go over budget and shows it in red. The ring
  stays until you move them apart.

  Every move is recorded in HISTORY, so leaving the screen
  never throws the work away.

-----------------------------------------------------------
HOW THE ROUTES ARE ORDERED
-----------------------------------------------------------

EVE drains a factory's input routes in the order they were
created, not evenly. A factory with two sources empties the
first one completely before touching the second.

So every factory is routed from its OWN launch pad first,
and only then from the others. On a multi-pad colony that is
the difference between the pads emptying together and one
pad emptying while the rest sit full.

This matters when you split a planet between two products:
each bank of factories drinks from the pad it sits on, so
the two products never compete for the same stock.

If you built a colony from an older copy of this tool and
see every factory pulling from one pad, regenerate it and
rebuild the input routes in game — EVE keeps the order a
route was created in, so editing the template alone is not
enough.

-----------------------------------------------------------
BILL OF MATERIALS
-----------------------------------------------------------

Under the layout strip, and it answers three questions.

  ONE FACTORY, PER CYCLE
    The recipe. What a single facility consumes each cycle
    and what it produces.

  HAUL IN · whole colony, per trip
    What you must bring, per hour and per collection trip.
    The per-trip column is the number you load a hauler
    against.

  COLLECT · whole colony, per trip
    What you take away, in units and in m3.

The per-trip columns are capped at what storage actually
survives. Ask 48h of a colony that jams at 33 and the panel
says so, then computes for 33 — a figure for 48 hours the
colony cannot reach would be a number you would pack a ship
against and be wrong.

EXTRACTED ON-PLANET replaces HAUL IN on extraction chains
for anything the planet mines itself.

When a colony runs more factories than its heads support,
the panel says so in words: "6 of 7 factories are fed by
extraction; the rest need 2,000/h of Planktic Colonies
hauled in". The shortfall was always visible in the haul-in
figures, but a quantity there reads the same whether it is a
deliberate import or the extractors falling behind.

-----------------------------------------------------------
PROXIMITY SCOUT
-----------------------------------------------------------

Finds the planets around a system so you can pick where to
set up.

  1. Click "Proximity Scout" in the rail.
  2. Type a system name — autocomplete suggests matches
     after two characters.
  3. Set JUMPS (0–10) for how far out to scan.
  4. Click SCAN, or press Enter.

It opens in its own window and leaves your build alone. You
can look at what is nearby without losing what you were
doing.

Results are grouped by system, closest first. Each system
header shows its security status, the planet types it
contains, its jump distance and its planet count. Click a
header to expand or collapse its planets.

Each planet card shows the planet's CCP icon, its name, its
type, and its radius in km — bigger radius means extractor
heads spread further apart and better yield.

CLICK A PLANET TO BUILD ON IT

  Hover a card and it offers "BUILD HERE". Clicking closes
  the Scout, returns you to Build, and carries BOTH the
  planet type and its exact radius across. That matters: the
  radius sets link length, and link cost scales with length,
  so a radius retyped by hand quietly reprices the whole
  colony.

  If you have not chosen a product yet, that is fine — the
  planet and radius are filled in and the panel asks you for
  the one thing still missing.

  If the chain you have selected cannot run there — an
  extraction chain on a planet without the raw material, or
  P4 anywhere but Barren/Temperate — it says so and changes
  nothing.

The SHOW row filters by planet type. Click a type to toggle
it, or ALL to bring everything back. Filtering redraws
instantly from the scan you already ran and automatically
expands the systems that still have matches, so you can hunt
for, say, every Lava planet within 5 jumps in one glance.
Your selection is remembered for next time.

Choose the P1 you mean to extract in the EXTRACT box and the
planet filter narrows to the types that carry its raw
material, disabling the rest.

Scanning is instant and works offline. The tool ships with
a snapshot of the map — 8,490 systems and 67,693 PI planets
— so resolving a name, walking the stargates and listing
planets all happen in memory. There is nothing to wait for
and nothing to break when EVE's servers are down.

One honest limit: wormhole systems have no fixed stargates,
so scanning from inside J-space returns that system alone.
Nothing can precompute a wormhole route.

-----------------------------------------------------------
LIBRARY
-----------------------------------------------------------

Your saved colonies, one card each. It starts empty; nothing
is shipped in it.

A card answers the four questions you ask standing in front
of a library, without opening anything: which chain, which
planet, how many structures, and when you saved it — plus a
breakdown of what those structures are.

The search box filters on the name and on the template's own
comment, so typing "barren" finds a barren colony you named
something else.

Three buttons per card:

  Load    opens the colony on the Build stage
  Edit    the same, but it checks first that the structures
          can be rearranged and tells you if they cannot,
          rather than landing you somewhere nothing moves
  Delete  asks first — there is no undo and no recycle bin

Opening a colony fills the whole settings panel in from it:
product, chain, planet type, radius and command center
level. None of that is read from the file's name or comment
— it is derived from the colony itself, so a template from a
forum post reads correctly too.

That matters for what happens next: because the panel now
describes what is on screen, changing the command center
level or the radius re-prices the colony you opened instead
of replacing it with a different one.

If you have unsaved hand-arranged work, Load and Edit ask
before replacing it.

-----------------------------------------------------------
JSON
-----------------------------------------------------------

Where a colony comes in and goes out as raw text.

  IMPORT
    "Open JSON file" reads a .json from disk.
    Paste into the box and press "Use pasted JSON", or use
    the "from clipboard" link to fill the box in one click.

    Either way the colony lands on the Build stage, with the
    settings panel filled in from it, exactly as a Library
    load does.

  EXPORT
    "Copy JSON" puts the colony on your clipboard in the
    compact form EVE reads.
    "Save JSON file" writes it to disk.

Below both, the colony currently on the stage, in the same
compact form the Copy button produces — so what you read is
what you would paste.

Importing in EVE: leave "Compress Pins" unticked. Ticked,
the game repacks the colony to its own spacing and the
layout you drew is lost without a word. Unticked, it names
any structure sitting too close and refuses, which is the
answer worth having.

-----------------------------------------------------------
ASSIGN P2 PER FACTORY
-----------------------------------------------------------

Only shown for the "P1 → P2 (Factory)" chain, because it is
the only one where every factory makes a P2 out of P1s.

Normally a colony makes one product on every factory. This
lets each Advanced Industry Facility make a DIFFERENT P2 on
the same proven layout: only the schematics and the route
payloads are rewritten, never the pins, the links or the
route paths.

You get an aggregated P1 shopping list, P2 output totals,
the factory allocation, and how many whole hourly cycles a
full launch-pad load runs.

-----------------------------------------------------------
HISTORY
-----------------------------------------------------------

Always on. There is nothing to switch on and nothing to
remember to press.

Every colony you build, every mixed plan and every structure
you drag is recorded. That last one is the point: a colony
you arranged by hand used to live only in the window that
drew it, so closing it threw the work away.

Click "HISTORY" in the Build panel to see the list, newest
first, with the time, what you were doing, the planet, and
the structure and link counts.

  RESUME            reopen that colony on the map
                    (or double-click the row)
  Save to library   keep it for good under a name
  Delete            drop one entry
  Clear all         forget everything

The newest 60 states are kept, in data/history.json. Going
back to a state you already had is recorded too, so you can
step forward again.

Saving to the library is the difference between "I was
working on this" and "I want to keep this". History is
automatic and rolls over; the library is yours until you
delete it.

-----------------------------------------------------------
SETTINGS
-----------------------------------------------------------

Click the gear icon in the title bar, from any screen.

  Opacity   — window transparency
  Text size — 80% to 200%, for every font in the app
  Theme     — 23 EVE faction colour schemes

Click APPLY to confirm. Text size and theme both rebuild the
window, so it will blink once.

Text size scales the panels as well as the text, so nothing
overlaps or gets cut off. The window then re-fits itself
around the new size.

The "?" button opens the About panel.

-----------------------------------------------------------
SYSTEM TRAY
-----------------------------------------------------------

Click the minimize button (—) to hide the main window to the
system tray.

  Single-click tray icon  — bring the window back
  Right-click tray icon   — menu with Show / Exit
  Double-click title bar  — collapse/expand the window

-----------------------------------------------------------
TIPS
-----------------------------------------------------------

- Chains within a tier trade hauling against output. For P4:
  P1 → P4 hauls the least and yields one High-Tech facility;
  P3 → P4 hauls finished P3 and yields many. P2 → P4 sits in
  between. The same applies to P1 → P3 versus P2 → P3.

- P0 → P2 is the low-maintenance option: a planet that feeds
  itself needs no imports at all when it holds both raw
  resources.

- Run the Proximity Scout before committing to a system, and
  use the type filter to find the planet types your chain
  needs. It no longer costs you the build you had started.

- Radius matters. Check it in-game and type the real value.

- Two products on one factory planet: set Pads 2,
  Factories 24, Arm len 6, then in game set half the
  factories to the second schematic. Two pads instead of
  three is what buys the 24th factory, and each bank of 12
  ends up on its own pad — which the route order then
  respects, so the two products do not compete for the same
  stock.

- Extraction planets are power-limited, not CPU-limited. A
  10-head extractor burns 8100 of the 19000 power a level 5
  command center has, which is why a balanced extraction
  colony leaves CPU unused. Spending that spare power on a
  second extractor leaves almost nothing for factories.

- If the layout panel says the extractors are short, either
  build fewer factories or accept that they idle part of the
  time. Factories that outrun their supply do not produce
  more, they just cost CPU and power.

-----------------------------------------------------------
TROUBLESHOOTING
-----------------------------------------------------------

Nothing appears on the planet
  — All three of product, chain and planet type have to be
    chosen. None of them is filled in for you. The panel
    names whichever one is still missing.

"Could not generate template"
  — The Command Center level is too low for that layout.
    Raise it, or choose a chain with fewer structures.

"Extractors N/h short of what the factories eat"
  — More factories than the ground can feed. Either lower the
    factory count, add an extractor if power allows, or raise
    the Extractor yield if your deposits really are that rich.
    Starved factories cost CPU and power without producing.

"Storage only lasts Nh, not the Nh asked for"
  — The colony cannot buffer the interval you picked. Add a
    launch pad, drop a factory, or accept a shorter interval.
    In automatic mode the generator has already tried; the
    warning means even its best attempt fell short.

"CPU / Power over budget"
  — Only reachable with manual counts. The template is still
    produced so you can see the shape of it, but EVE will
    refuse to build it as-is.

"Link N–N needs N m3/h — over the 1250 a level-0 link moves"
  — An arm is carrying more than its link can pass. The link
    closest to the pad carries every factory behind it, so
    this comes from long arms on a bulky chain, P3 → P4
    above all. Lower Arm len, spread the same factories over
    one more pad, or upgrade that link in game. Ignoring it
    does not break the import; the factories behind that
    link simply cannot all be fed at once.

Two structures on top of each other
  — Should not happen any more; every colony the tool can
    build is checked against EVE's minimum spacing. If you
    see it, it came from a hand drag: both structures wear a
    dashed red ring until you move them apart. EVE refuses
    to import a colony with structures touching.

All factories drain the same launch pad
  — The template was generated before route order was fixed,
    or the colony was built from an old copy. See HOW THE
    ROUTES ARE ORDERED above: regenerate and rebuild the
    input routes, since EVE keeps the order a route was
    created in.

The layout panel is greyed out
  — Manual counts are only available for the extraction and
    single-stage factory chains. P1 → P3, P1 → P4 and
    P2 → P4 build a fixed geometry that cannot be resized.

"Collect every" changes nothing
  — Almost always because the colony already outlasts the
    interval; the panel confirms this with "already covered".
    It is a minimum to meet, not a size to hit, so it only
    acts when the colony would fall short. Extraction planets
    rarely need it at all. Raise Pads manually if you want a
    bigger buffer regardless.

The window keeps resizing itself
  — That is the fit. It follows what there is to show, so it
    only moves when the colony's size actually changes. Drag
    an edge and it stays where you put it until then.

Radius shows "—" in the Proximity Scout
  — The offline map snapshot could not be read. The tool
    normally answers from the copy inside the executable and
    never needs the network for this.

"No systems found" / scan errors
  — Check the system name first. The Scout works offline
    from the bundled snapshot; it only reaches for ESI if
    that snapshot is missing.

App crashes on launch (from source)
  — Install the dependencies: pip install -r requirements.txt
  — pystray is optional, but required for tray support.
